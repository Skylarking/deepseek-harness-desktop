# @deepseek-ai/dsh-client-ui-workspace-files

[English](README.md) | 中文

可逆的工作空间文件浏览界面。浏览器半边同时在 `shell.hero.utilities` 和 `conversation.session.header.utilities` 中加入“项目文件”图标，并占用布局拥有的 `shell.rightPanel` 分栏。全高目录树与有界文本或图片预览始终在面板内左右排列，窄面板宽度下也会同时显示，两者之间的分界线支持鼠标和键盘调节。工具栏可以输入工作空间内的绝对或相对目录路径，并用紧凑的填色选择框显示实时客户端工作空间列表。内外两条可拖动分界线都会在交互时高亮且不会遮挡会话。

本包只拥有按钮和面板内容。从 cordis.yml 删除本包条目会同时删除按钮、关闭并移除分栏、丢弃选择、展开和预览状态，不改变工作空间或会话数据；同时删除 Host 网关条目后，文件读取权限也一并消失。

## 模型体验

无，因为此界面不改变提示词、工具、消息或提供方请求。

#### KV Cache 影响

无。

## 已知限制与暂缓事项

- 预览仅只读，不提供编辑、搜索、语法高亮或任意二进制渲染。
